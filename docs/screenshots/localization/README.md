# Localization review captures

Local production build of version 0.23.0, captured in Chromium. These are browser
emulations, not Vercel-preview screenshots or physical-device acceptance.

The selector and gameplay views use 390×844 phone viewports. The complete Settings
pages use 320×844 phone viewports from the localization audit. All four locales
were checked at 320px phone and 800px tablet widths in both themes, including
language persistence, played-game preservation and offline routes.
